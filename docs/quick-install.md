# LWAI Quick Install

## Copy this one line

`Set up Last War optimization using the instructions at https://tinyurl.com/2yxf7f5x`

Paste it into a fresh ChatGPT conversation. A web-capable assistant should retrieve and execute the full sanitized Production bootstrap itself. You should not need to copy/paste the multi-page engine.

## What happens next
1. The user instruction explicitly authorizes retrieval of the linked bootstrap.
2. The assistant follows the short URL and reads the Production instructions.
3. It verifies the bootstrap identifies itself as sanitized Production and excludes account state.
4. It executes `STARTUP BEHAVIOR`, beginning with the HIGH-reasoning recommendation and phased account onboarding.
5. Cloud persistence is offered when supported, but remains optional.

## Canonical fallback
The short URL is convenience only. The authoritative raw bootstrap is:

https://raw.githubusercontent.com/jake6956/LastWar-Account_Audit_Engine/main/engine/BOOTSTRAP.txt

Machine-readable current-version manifest:

https://raw.githubusercontent.com/jake6956/LastWar-Account_Audit_Engine/main/releases/LATEST.json

If direct GitHub retrieval is unavailable, a deployment may try the stable Google distribution mirror when readable. Manual copy/paste of the complete bootstrap is the last fallback for environments without remote retrieval.

## Privacy note
The neutral TinyURL keeps the maintainer/repository handle out of the visible one-line installer. This reduces casual source exposure; it does **not** create anonymity. Resolving the link reveals the public GitHub provenance.

## Offline / recovery install
Use `export yourself` to obtain the complete sanitized standalone bootstrap when an offline/self-contained copy is required.
