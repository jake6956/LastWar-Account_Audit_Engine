LAST WAR AI — PUBLIC INSTALLER / ENGINE PROXY CONTRACT

SANITIZED: YES
ACCOUNT STATE INCLUDED: NO

PURPOSE
The public client should only need https://lastwarai.com. Cloudflare resolves current GitHub Production server-side and proxies one complete sanitized engine snapshot from the exact immutable commit. The user's ChatGPT session must not be required to call GitHub's branch API or raw-content endpoints during installation.

PLAYER UX
The root response displays the canonical installer sentence:
Set up Last War optimization using the instructions at https://lastwarai.com

A human is told to paste that sentence, not the page. If the entire page is pasted anyway, that is a supported alternate path and the assistant continues without repaste/restart.

ROOT RESPONSE CONTRACT
A successful HTTP 200 response from https://lastwarai.com MUST contain:
PASTED_CONTENT_MODE: CONTINUE_INSTALL
RESOLUTION_STATUS: LIVE_GITHUB_SERVER_SIDE
RESOLVED_PRODUCTION_COMMIT: <40-character lowercase hexadecimal Git SHA>
ENGINE_URL: https://lastwarai.com/engine/<same SHA>

The assistant must fetch ENGINE_URL from LastWarAI.com, not GitHub, and continue installation without asking the user for JSON, SHA values, URLs, or other technical steps.

PINNED ENGINE CONTRACT
GET /engine/<40-hex SHA> proxies engine/BOOTSTRAP_FULL.txt from that exact GitHub commit. The response must:
- be text/plain UTF-8;
- include X-LWAI-Commit with the same SHA;
- use an immutable cache policy because exact-SHA bytes cannot change;
- begin with a first-party handoff stating Stage-0 live resolution is already complete for this startup;
- include the complete sanitized LWAI fallback engine from the same exact commit;
- never include private account state.

TRUST
GitHub main remains the underlying Production source/authority. LastWarAI.com is the first-party resolver and transport proxy. Cloudflare performs the live GitHub resolution and exact-commit source fetch server-side. The client never substitutes search results, mutable raw main, cached README pages, shorteners, redirects, or model memory for the resolved immutable SHA.

FAILURE
If Cloudflare cannot establish a valid live GitHub SHA, root returns HTTP 503 with the canonical installer sentence and a retry instruction; never guess a commit. If an exact pinned engine cannot be retrieved or fails sanity checks, /engine/<SHA> fails closed rather than returning partial or unrelated content.
