LAST WAR AI — PUBLIC BOOTSTRAP RESOLVER CONTRACT

SANITIZED: YES
ACCOUNT STATE INCLUDED: NO

The live first-party endpoint at https://lastwarai.com resolves the current GitHub Production commit server-side for each installation request.

A successful HTTP 200 response MUST contain:
RESOLUTION_STATUS: LIVE_GITHUB
RESOLVED_PRODUCTION_COMMIT: <40-character lowercase hexadecimal Git SHA>
EXACT_BOOTSTRAP_URL: https://raw.githubusercontent.com/jake6956/LastWar-Account_Audit_Engine/<same SHA>/engine/BOOTSTRAP.txt
LIVE_REF_SOURCE: https://api.github.com/repos/jake6956/LastWar-Account_Audit_Engine/branches/main

CLIENT CONTRACT
The client must not be required to call GitHub's branch API again before starting. Validate the SHA format, verify the exact bootstrap URL contains the same SHA, retrieve that exact-commit bootstrap, and pin the startup transaction to the same immutable commit.

TRUST
GitHub main remains underlying Production authority. LastWarAI.com is first-party discovery/live-resolution transport that retrieves that authority server-side. Search results, mutable raw main, cached README pages, URL shorteners, redirects and model memory are not substitutes for the resolved immutable SHA.

FAILURE
If the server-side resolver cannot establish a valid live GitHub SHA, return HTTP 503 and do not fabricate or guess a commit.
